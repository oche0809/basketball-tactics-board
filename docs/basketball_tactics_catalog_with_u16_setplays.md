# 中学校バスケ部用・デジタル作戦盤 戦術カタログ

作成日: 2026-09-26（U16以降セットプレー追補）
用途: 中学校バスケットボール部のセットオフェンス学習・作戦確認

## 方針

- 戦術の動きは、公開資料で確認できた内容を要約している。
- 元資料の図・文章をそのまま転載せず、アプリ実装用に構造化している。
- 出典が確認できるものだけを「verified」として登録する。
- コート上の正確な座標は、元資料の図をアプリ上で再構成する際に最終確認する。
- 番号（1～5）は資料上の O1～O5 に対応する。
- 「第1オプション」等は、資料に明示された選択肢を優先して記載し、明示されない場合は空欄にする。

## 指導体系の位置付け

JBAのU15指導内容指針案では、1on1、オフボールスクリーン、5アウト、4アウト1インなどがU15までに位置付けられ、セットプレーはU16以降に配置されている。JBA資料の趣旨として、育成年代では特定チームだけで通用する固定戦術より、他のチーム・カテゴリーでも応用できる原則を身につけることが重視されている。

## A. エンドスローイン（BLOB）

### BLOB-01 Box Gator
- 形式: Box
- 主なテーマ: ダブル・エレベータースクリーン
- 流れ:
  1. O4・O5がO2のためにエレベータースクリーンを作る。
  2. O2がスクリーンの間をカットし、パスを受けてシュートを狙う。
  3. O2のカット後、O3・O5が2回目のエレベータースクリーンを作る。
  4. O4がその間をカットし、ゴール下でパスを受ける。
- 主要オプション: O2のシュート、O4のゴール下。
- 出典: Coach's Clipboard “Box Baseline Out-of-Bounds Basketball Plays”
- 出典URL: https://www.coachesclipboard.net/OBBoxPlays.html
- 備考: 元資料の動線をアプリ用に再構成する際、スクリーンの位置は図で確認する。

### BLOB-02 Box-1
- 形式: Box
- 主なテーマ: クロススクリーン＋シール＋ロール
- 流れ:
  1. O4がO5をスクリーンし、O5が反対側ブロックへカットする。
  2. O4はスクリーンした後にディフェンダーをシールし、ゴールへロールする。
  3. O1はO3のダウンスクリーンを使ってトップへ出る。
  4. O3はスクリーン後にウィークサイド・コーナーへ移動する。
- 主要オプション: O5、ディフェンスがスイッチした場合のO4、外側のO1/O3。
- 出典: Coach's Clipboard “Box Baseline Out-of-Bounds Basketball Plays”
- 出典URL: https://www.coachesclipboard.net/OBBoxPlays.html

### BLOB-03 Box-2
- 形式: Box
- 主なテーマ: バックスクリーン→ダウンスクリーン→シューター
- 流れ:
  1. O3がO5をバックスクリーンして反対側ローブロックへ進ませる。
  2. O4は一度ゴール方向へフェイクしてコーナーへ出て、インバウンドパスを受ける。
  3. O1はボールサイドのトップへ出る。
  4. O4がO1へパスする。
  5. O4がO2へダウンスクリーンをかけ、O2がボールサイド・コーナーへカットする。
  6. O1からO2へパスしてコーナーシュートを狙う。
- 主要オプション: O2のコーナーシュート、ディフェンダーが出た場合のO4ポスト。
- ゾーン用変化: O4が外側のローポスト側ゾーンディフェンダーへダウンスクリーン。
- 出典: Coach's Clipboard “Box Baseline Out-of-Bounds Basketball Plays”
- 出典URL: https://www.coachesclipboard.net/OBBoxPlays.html

### BLOB-04 Box-3
- 形式: Box
- 主なテーマ: クロススクリーン＋ウイングへのスクリーン
- 流れ:
  1. O4がO5をスクリーンし、O5がカットしてインバウンドパスを狙う。
  2. O4はスクリーン後にシールし、ゴール下でパスを狙う。
  3. O1がO2をスクリーンし、O2がウイングへカットする。
  4. O1はスクリーン後にトップへ出る。
- 主要オプション: O5/O4のインサイド、O2のウイングシュート。
- 出典: Coach's Clipboard “Box Baseline Out-of-Bounds Basketball Plays”
- 出典URL: https://www.coachesclipboard.net/OBBoxPlays.html

### BLOB-05 Box-54
- 形式: Box
- 主なテーマ: ポストへのバックスクリーン＋スイッチ対応
- 流れ:
  1. O5がO4をバックスクリーンする。
  2. インバウンドパスはボールサイド・コーナーのO2へ入れる。
  3. O4がO5のスクリーンを使ってゴール方向へカットし、レイアップを狙う。
  4. ディフェンスがスイッチしてO4についてきた場合、O4は反対側ブロックへクリアする。
  5. O5はシールしてボールサイド・ブロックへロールし、パスを狙う。
- 主要オプション: O4のレイアップ、O5のレイアップ、O2またはO1のアウトサイドシュート。
- 出典: Coach's Clipboard “Box Baseline Out-of-Bounds Basketball Plays”
- 出典URL: https://www.coachesclipboard.net/OBBoxPlays.html

### BLOB-06 Wheel
- 形式: Stack / Wheel
- 主なテーマ: 連続カット
- 流れ:
  1. O1がスタックの外側を大きくカールしてゴールへ向かい、パスを狙う。
  2. パスがなければO1は反対側ショートコーナーへクリアする。
  3. O2が少し遅れて同じようにカールし、ボールサイド・ショートコーナーでパスを狙う。
  4. O1・O2のカット後、O4がペイントへ入り、O5がトップへ出る。
  5. O5へパスが入った場合、O3が反対側ローポストへスリップしてリターンパスを狙う。
- 出典: Coach's Clipboard “Miscellaneous Baseline Out-of-Bounds Plays”
- 出典URL: https://www.coachesclipboard.net/OBPlaysMore.html

## B. サイドスローイン（SLOB）

### SLOB-01 Triangle
- 形式: Triangle
- 主なテーマ: スクリーン＋シューターのトップへの移動
- 流れ:
  1. O2がO3をスクリーンし、O3がコーナーへカットする。
  2. O5がO2へダウンスクリーンをかける。
  3. O2がトップへカットして3Pを狙う。
  4. ディフェンスがスイッチした場合、O5がミスマッチを利用してシールし、インバウンドパスからレイアップを狙う。
- 出典: Coach's Clipboard “Sideline Out-Of-Bounds Basketball Plays”
- 出典URL: https://www.coachesclipboard.net/SidelinePlays.html

### SLOB-02 Box-1
- 形式: Box
- 主なテーマ: ダウンスクリーン→バックスクリーン→レイアップ
- 流れ:
  1. O4・O5がO2・O3へダウンスクリーンをかける。
  2. O2・O3が3Pエリアへカットする。
  3. O3がインバウンドパスを受け、O2はセーフティとして残る。
  4. O5がO1へバックスクリーンをかける。
  5. O1がベースライン側からゴールへカットし、O3からのパスを狙う。
  6. 第2オプションとしてO5がシールしてゴールへロールする。
  7. どちらも難しい場合はO3からO2へ戻し、通常のハーフコートオフェンスへ移行する。
- 出典: Coach's Clipboard “Sideline Out-Of-Bounds Basketball Plays”
- 出典URL: https://www.coachesclipboard.net/SidelinePlays.html

### SLOB-03 Box-2
- 形式: Box
- 主なテーマ: Screen the Screener
- 対マンツーマンの流れ:
  1. O2がO1をダウンスクリーンする。
  2. その後O5・O4のスタッガードスクリーンを使い、O2がシューターとしてボールを受ける。
  3. O3またはO1からO2へパス。
  4. O2はシュート、またはO4へのポストパスを選択できる。
- ゾーン向け変化も資料に掲載。
- 出典: Coach's Clipboard “Sideline Out-Of-Bounds Basketball Plays”
- 出典URL: https://www.coachesclipboard.net/SidelinePlays.html

### SLOB-04 Circle
- 形式: Double Screen / Staggered Screen
- 主なテーマ: シューターを2段階でスクリーン
- 流れ:
  1. O2がO4・O5のダブルスクリーンを使って反対ウイングへカールする。
  2. O1がO2に続いて動き、O3からインバウンドパスを受ける。
  3. O5・O4がすばやくスタッガードスクリーンを作る。
  4. O2がそのスクリーンを使って戻り、O1からパスを受ける。
  5. O2が3Pまたはドライブを狙う。
  6. スイッチならO5がスクリーンをスリップしてインサイドでパスを狙う。
- 出典: Coach's Clipboard “Sideline Out-Of-Bounds Basketball Plays”
- 出典URL: https://www.coachesclipboard.net/SidelinePlays.html

### SLOB-05 Pairs
- 形式: 2組のスクリーン
- 主なテーマ: シューター＋インサイドの2択
- 流れ:
  1. O4がO2をスクリーンし、O2が上または下を使って出る。
  2. O3がO2への第1パスを狙う。
  3. O2はシュート、またはO4のポストへパスする。
  4. O5がO1をスクリーンし、O1は安全なインバウンドパスの選択肢になる。
  5. O5自身がインバウンドパスを受ける選択肢もある。
- 出典: Coach's Clipboard “Sideline Out-Of-Bounds Basketball Plays”
- 出典URL: https://www.coachesclipboard.net/SidelinePlays.html

### SLOB-06 Stack-2
- 形式: Stack
- 主なテーマ: スタックからの2方向のカット
- 流れ:
  1. O1がO2をスクリーンし、その後O1自身がその位置を置き換える。
  2. O2がVカットをフェイクしてO1のスクリーンを使い、ニアサイドを走る。
  3. パスがなければO2はボールサイド・コーナーへ移動。
  4. O5がO4へバックスクリーンをかけ、O4が反対側へカットする。
  5. 第2オプションとしてO4へのロブパスがある。
  6. どちらも難しい場合はO1またはO5へ入れて通常のオフェンスへ。
- 出典: Coach's Clipboard “Sideline Out-Of-Bounds Basketball Plays”
- 出典URL: https://www.coachesclipboard.net/SidelinePlays.html

### SLOB-07 Kansas
- 形式: Stack
- 主なテーマ: カールカットとバックカットの読み替え
- 流れ:
  1. O1がスタックからポップアウトしてインバウンドパスを受け、トップ付近へドリブル。
  2. O4は反対コーナーへクリア。
  3. O2がO5のスクリーンを使ってカールし、O1からパスを受ける。
  4. O2はシュート、またはO5へのパスを選択する。
  5. 同じプレーを続けて使う場合、ディフェンスがカールを警戒したときはO2がカールをフェイクしてバックカットする変化が資料に示されている。
- 出典: Coach's Clipboard “Sideline Out-Of-Bounds Basketball Plays”
- 出典URL: https://www.coachesclipboard.net/SidelinePlays.html

### SLOB-08 Celtics
- 形式: Down Screen → Fake Handoff / Handoff + PnR
- 主なテーマ: 1プレーから複数の展開へ
- 流れ:
  1. O4がO1へダウンスクリーン。
  2. O1がトップへ出てインバウンドパスを受ける。
  3. O4はポストへ入り、速いパスを狙う。なければ反対側ショートコーナーへ移動。
  4. O1がフェイク・ハンドオフを使ってドライブする選択肢。
  5. さらにO1からO3へのハンドオフへ展開し、O3がO5とピック＆ロール／ピック＆ポップを行う選択肢。
  6. O1は左ウイングへクリアする。
- 出典: Coach's Clipboard “Sideline Out-Of-Bounds Basketball Plays”
- 出典URL: https://www.coachesclipboard.net/SidelinePlays.html

## C. ハーフコート

### HC-01 5-Out Pass & Cut / Replacing the Cutter
- 形式: 5-Out Motion
- 主なテーマ: パス→カット→空いた場所を埋める
- 流れ:
  1. ボール保持者がパスしてリングへカットする。
  2. 近くの選手が空いた場所へ向かい、ペリメーターを埋める。
  3. 他の選手もバランスを取り、5人の位置を保つ。
  4. 3Pラインをただ追うのではなく、リングへ脅威を持ってカットしてから外へ出る考え方を含む。
- 出典: FIBA/WABC Level 1 Coaching Manual
- 出典URL: https://assets.fiba.basketball/image/upload/documents-corporate-wabc-coaching-level-manuals-level-1-eng.pdf
- 補助動画: YouTube “5 Out Pass and Cut Basketball Offense | 5 Out Basketball Play” https://www.youtube.com/watch?v=AD12697wncU

### HC-02 5-Out Purposeful Movement / Timing & Spacing
- 形式: 5-Out Motion
- 主なテーマ: カットのタイミング、スペーシング、守備の読み
- 流れ:
  1. トップからパス＆カット。
  2. カッターがフリースローラインを越えるまでは、別の選手が入れ替わることができる。
  3. カッターがフリースローラインを越えたら、リングへ進み続ける。
  4. 次の選手はカッターが十分にリングへ向かってから空いた位置を埋める。
- 出典: FIBA/WABC Level 1 Coaching Manual
- 出典URL: https://assets.fiba.basketball/image/upload/documents-corporate-wabc-coaching-level-manuals-level-1-eng.pdf

### HC-03 5-Out Pass & Screen Away
- 形式: 5-Out Motion + Off-ball Screen
- 主なテーマ: パス後のスクリーン
- 流れ:
  1. ウイングへパス。
  2. パスした選手が離れたサイドの選手へスクリーンする。
  3. スクリーンを使う選手が外へ出る、またはリングへカットする。
  4. パス＆カットを行った選手がベースライン側の選手へスクリーンする展開もある。
- 出典: FIBA/WABC Level 1 Coaching Manual
- 出典URL: https://assets.fiba.basketball/image/upload/documents-corporate-wabc-coaching-level-manuals-level-1-eng.pdf

### HC-04 5-Out Ball Reversal
- 形式: 5-Out Motion
- 主なテーマ: ボールの逆サイド展開と守備の移動
- 流れ:
  1. 連続してパスしてボールを反対側へ移す。
  2. パスに合わせて各選手も位置を移動する。
  3. 守備が新しい位置へ移動している間にドライブの機会を探す。
- 出典: FIBA/WABC Level 1 Coaching Manual
- 出典URL: https://assets.fiba.basketball/image/upload/documents-corporate-wabc-coaching-level-manuals-level-1-eng.pdf

### HC-05 UCLA Cut
- 形式: High Post Screen + Pass & Cut
- 主なテーマ: ハイポストを使ったカット
- 流れ:
  1. ボールをウイング／トップ間でパスする。
  2. パスした選手がリングへカットする。
  3. ハイポストの選手がスクリーンを作り、カッターの進路を助ける。
  4. カットでパスがなければ外へ出て次の攻撃へつなぐ。
- 出典: FIBA/WABC Level 3 Coaching Manual
- 出典URL: https://assets.fiba.basketball/image/upload/documents-corporate-wabc-coaching-manual-level-3-eng.pdf
- 注記: UCLA Cutには複数の実装形がある。アプリでは「UCLAの基本構造」として登録し、チーム固有の5人の配置は別データとして持たせる。

### HC-06 Flex
- 形式: Continuity Offense
- 主なテーマ: バックドア系ベースラインカット＋Screen the Screener
- 流れ:
  1. ベースラインカットをバックスクリーンで作る。
  2. ボールをリバースする。
  3. 先にスクリーンした／関係した選手が別の選手へスクリーンを行う。
  4. 反対側でも同様の動きを続け、連続して攻撃できる。
- 出典: FIBA/WABC Level 3 Coaching Manual
- 出典URL: https://assets.fiba.basketball/image/upload/documents-corporate-wabc-coaching-manual-level-3-eng.pdf

## 参考：Hornsを追加する場合

HornsはFIBA/WABC Level 3に具体例が掲載されている。
- 1が3のスクリーンを使ってドリブル。
- 3が5のスクリーンを使ってキーカット。
- 4が2へスクリーンをかけ、2がターンアウト。
- 1は2または3へパスを選べる。
- 3はキャッチ＆シュートまたはドライブへ移れる。

出典: https://assets.fiba.basketball/image/upload/documents-corporate-wabc-coaching-manual-level-3-eng.pdf

ただし、初期版アプリでは20件を優先し、Hornsは追加枠として扱う。

## 実装上の重要事項

1. 「戦術名」と「チーム内での呼び名」を別項目にする。
2. 同じ戦術でも左右反転できるようにする。
3. O1～O5を選択して、その選手だけを強調できるようにする。
4. STEPは1アクションずつ進める。
5. 「全体」「自分」「ボール」を表示モードとして切り替える。
6. 第1オプションが守られたときの次の選択肢が資料に記載されている場合は、それもSTEPに含める。
7. チーム固有の動きは、公開資料の戦術とは別レイヤーにする。
8. 出典URLをアプリ内部のデータとして保持する。
9. 元資料の画像をコピーして表示せず、コート・選手・矢印はSVG等で独自描画する。
10. 出典の動きとチーム独自の変更を混同しない。
