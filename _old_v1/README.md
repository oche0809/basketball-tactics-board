# バスケットボール 作戦ボード

中学校体育のバスケットボール授業用の、作戦盤Web教材です。
インターネット接続・サーバー・ログインは不要です。

## 開き方

- `index.html` をダブルクリックする（Chrome / Edge / Safari）
- または、ターミナルで `./run.sh` を実行する

USBメモリや共有フォルダにフォルダごとコピーしても動きます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `data/tactics.js` | **戦術データ**（先生が編集するのはこのファイルだけです） |
| `index.html` / `app.js` / `style.css` | 画面（編集不要） |
| `check-data.js` | データの入力ミスをチェックするスクリプト |

## 戦術を追加・修正する

1. `data/tactics.js` を開く
2. 既存の戦術 `{ ... }` を1つコピーして、`window.TACTICS = [ ... ]` の中に貼り付ける
3. `id`（重複しない英数字）と中身を書き換える
4. 保存して、ブラウザを再読み込みする

選手の位置は `[x, y]` で書きます（1 = 10cm）。

- x：0（左サイドライン）〜 150（右サイドライン）
- y：0（エンドライン）〜 120（画面に映る範囲）
- ゴールは `[75, 16]` 付近です
- コートの外は、マイナスの値（例：エンドの外 `[92, -6]`、左サイドの外 `[-6, 75]`）で書きます

**教師モードをONにしてコートをクリックすると、その場所の座標が表示されます。**

編集した後は、次のコマンドで入力ミスをチェックできます。

```
node check-data.js
```

## 出典の表示

`source.type` の値によって、表示されるラベルが変わります。

- `"jba"` → 「JBA公式資料に基づく」（JBAの資料で内容を確認できた場合だけ使ってください）
- `"book"` → 「出典あり」
- `"unverified"` → 「出典未確認・サンプル」

最初に入っている3つの戦術は、動きを確認するための **サンプルデータ（出典未確認）** です。
授業で使う前に、先生が動きを確認・修正してください。
